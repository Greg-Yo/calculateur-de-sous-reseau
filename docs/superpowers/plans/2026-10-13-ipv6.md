## Review Focus

Les cas qui risquent le plus de produire un résultat faux sans que ça se voie. Chacun a son test dans la tâche indiquée :

1. **Le masque /64** : `-1L << 64` vaut `-1L` en Java. Sans cas particulier, la moitié basse d'un /64 serait pleine de 1. → tâche 4 (`buildsMasksOnBothHalves`, `everyMaskHasExactlyPrefixBitsSet`).
2. **`"".split(":", -1)` renvoie un élément vide** : sans traitement, `::1` serait refusé ou mal lu. → tâche 2.
3. **Égalité entre deux suites de zéros** : la RFC 5952 compresse la première (`::1:8000:0:0:0`, et non `0:0:0:1:8000::`). → tâches 3 et 4.
4. **La retenue et le décalage à cheval** : `::ffff:ffff:ffff:ffff + 1` et le 5e sous-réseau /66 d'un /62. → tâches 4 et 7.
5. **Le haut de l'espace d'adressage** (`ffff:…/64` découpé en /66) : pas de débordement, pas de nombre négatif affiché. → tâche 7.

- [ ] **Step 3 : 🎓 À toi — écrire `parseStrict`**

Claude fournit la structure de la classe et les petites méthodes d'aide (`parse`, `isHexDigit`, `hintFor`). L'apprenant écrit `parseStrict`, `groups` et `groupValue` en suivant l'ordre des vérifications de la spec (§6.1) : vide → caractères → nombre de `::` → groupe vide → nombre de groupes → longueur d'un groupe.

Indices :
- `text.indexOf("::")`, puis chercher un second `::` à partir de la position **+ 1** ;
- une partie vide (à gauche de `::1`) ne contient **aucun** groupe : ne pas appeler `split` dessus ;
- un tableau `int[8]` initialisé à 0 : les groupes de gauche au début, ceux de droite à la fin ;
- `high = (high << 16) | values[i]` pour les groupes 0 à 3, idem pour `low` avec 4 à 7.

**Implémentation de référence :**

```java
package com.coco.subnet.model;

import static com.coco.subnet.model.ErrorCode.EMPTY_GROUP;
import static com.coco.subnet.model.ErrorCode.EMPTY_INPUT;
import static com.coco.subnet.model.ErrorCode.GROUP_TOO_LONG;
import static com.coco.subnet.model.ErrorCode.INVALID_CHARACTERS;
import static com.coco.subnet.model.ErrorCode.MULTIPLE_DOUBLE_COLON;
import static com.coco.subnet.model.ErrorCode.WRONG_GROUP_COUNT;

/**
 * Une adresse IPv6 : 128 bits rangés dans deux long.
 * high = les 4 premiers groupes, low = les 4 derniers (signés : 8000:: et plus ont un high négatif).
 */
public record Ipv6Address(long high, long low) {

    public static Ipv6Address parse(String input, String field) {
        if (input == null || input.isBlank()) {
            throw InvalidInputException.of(EMPTY_INPUT, field, "L'adresse est obligatoire");
        }
        return parseStrict(input.strip(), field);
    }

    /** Sans retirer les espaces : utilisé par Ipv6Cidr, qui a déjà nettoyé la saisie complète. */
    static Ipv6Address parseStrict(String text, String field) {
        if (text.isEmpty()) {
            throw InvalidInputException.of(EMPTY_INPUT, field, "L'adresse est obligatoire");
        }
        for (char c : text.toCharArray()) {
            if (!isHexDigit(c) && c != ':') {
                throw InvalidInputException.of(INVALID_CHARACTERS, field,
                        "Caractère non autorisé : '" + c + "'" + hintFor(c));
            }
        }
        int doubleColon = text.indexOf("::");
        // + 1 et non + 2 : dans "1:::2", le second "::" commence juste après le premier ':'
        if (doubleColon >= 0 && text.indexOf("::", doubleColon + 1) >= 0) {
            throw InvalidInputException.of(MULTIPLE_DOUBLE_COLON, field, "« :: » ne peut apparaître qu'une seule fois");
        }
        String[] left = groups(doubleColon < 0 ? text : text.substring(0, doubleColon), field);
        String[] right = doubleColon < 0 ? new String[0] : groups(text.substring(doubleColon + 2), field);
        int written = left.length + right.length;
        if (doubleColon < 0 && written != 8) {
            throw InvalidInputException.of(WRONG_GROUP_COUNT, field,
                    "Une adresse IPv6 contient 8 groupes (" + written + " trouvés)");
        }
        if (doubleColon >= 0 && written > 7) {
            throw InvalidInputException.of(WRONG_GROUP_COUNT, field,
                    "Avec « :: », au plus 7 groupes peuvent être écrits (" + written + " trouvés)");
        }
        // Les groupes absents (remplacés par "::") restent à 0
        int[] values = new int[8];
        for (int i = 0; i < left.length; i++) {
            values[i] = groupValue(left[i], field);
        }
        for (int i = 0; i < right.length; i++) {
            values[8 - right.length + i] = groupValue(right[i], field);
        }
        long high = 0;
        long low = 0;
        for (int i = 0; i < 4; i++) {
            high = (high << 16) | values[i];
            low = (low << 16) | values[i + 4];
        }
        return new Ipv6Address(high, low);
    }

    /** Morceaux entre les ':'. Une partie vide (à gauche de "::1") ne contient aucun groupe. */
    private static String[] groups(String part, String field) {
        if (part.isEmpty()) {
            return new String[0];
        }
        // -1 : garder les morceaux vides en fin de chaîne ("1:2:" → 3 morceaux)
        String[] groups = part.split(":", -1);
        for (String group : groups) {
            if (group.isEmpty()) {
                throw InvalidInputException.of(EMPTY_GROUP, field,
                        "Groupe vide : un ':' seul est interdit en début ou en fin d'adresse");
            }
        }
        return groups;
    }

    private static int groupValue(String group, String field) {
        // plus de 4 chiffres : refusé sans appeler parseInt
        if (group.length() > 4) {
            throw InvalidInputException.of(GROUP_TOO_LONG, field,
                    "Le groupe '" + group + "' dépasse 4 chiffres hexadécimaux");
        }
        return Integer.parseInt(group, 16);
    }

    /** Pas de Character.digit : il accepterait les chiffres Unicode « pleine chasse ». */
    private static boolean isHexDigit(char c) {
        return (c >= '0' && c <= '9') || (c >= 'a' && c <= 'f') || (c >= 'A' && c <= 'F');
    }

    private static String hintFor(char c) {
        return switch (c) {
            case '.' -> " (la notation IPv4 intégrée n'est pas prise en charge)";
            case '%' -> " (les identifiants de zone ne sont pas pris en charge)";
            default -> "";
        };
    }
}
```

```java
    /** Groupe n° index (0 à 7), entre 0 et 0xFFFF. */
    public int group(int index) {
        long half = index < 4 ? high : low;
        int shift = 16 * (3 - index % 4);
        return (int) ((half >>> shift) & 0xFFFF);
    }

    /** Forme complète : 8 groupes de 4 chiffres, sans "::". */
    public String toFullString() {
        StringJoiner joiner = new StringJoiner(":");
        for (int i = 0; i < 8; i++) {
            joiner.add(String.format("%04x", group(i)));
        }
        return joiner.toString();
    }
```

- [ ] **Step 4 : 🎓 À toi — écrire `toString`**

Indices : parcourir les 8 groupes en repérant le début et la longueur de chaque suite de zéros ; ne garder une suite que si elle est **strictement** plus longue que la meilleure déjà trouvée (c'est ce qui garde la première en cas d'égalité) ; commencer avec une « meilleure longueur » de 1 pour ignorer les zéros isolés.

**Implémentation de référence :**

```java
    /** Forme compressée de la RFC 5952. */
    @Override
    public String toString() {
        // Plus longue suite d'au moins 2 groupes à zéro ; « > » garde la première en cas d'égalité
        int bestStart = -1;
        int bestLength = 1;
        int i = 0;
        while (i < 8) {
            if (group(i) != 0) {
                i++;
                continue;
            }
            int start = i;
            while (i < 8 && group(i) == 0) {
                i++;
            }
            if (i - start > bestLength) {
                bestStart = start;
                bestLength = i - start;
            }
        }
        StringBuilder text = new StringBuilder();
        for (int g = 0; g < 8; g++) {
            if (g == bestStart) {
                text.append("::");
                g += bestLength - 1;
                continue;
            }
            if (!text.isEmpty() && text.charAt(text.length() - 1) != ':') {
                text.append(':');
            }
            text.append(Integer.toHexString(group(g)));
        }
        return text.toString();
    }
```

### Task 4 : Opérations binaires sur 128 bits

**Notion :** le masque est coupé en deux moitiés ; `-1L << 64` vaut `-1L` en Java (décalage modulo 64), d'où les cas /0 et /64.
```java
    public static final Ipv6Address ONE = new Ipv6Address(0L, 1L);

    /** Masque pour un préfixe /0 à /128, coupé en deux moitiés de 64 bits. */
    public static Ipv6Address maskOf(int prefix) {
        if (prefix < 0 || prefix > 128) {
            throw new IllegalArgumentException("Préfixe hors limites : " + prefix);
        }
        // Java décale modulo 64 : -1L << 64 vaut -1L, d'où les cas /0 (pour high) et /64 (pour low)
        long high = prefix == 0 ? 0L : (prefix >= 64 ? -1L : -1L << (64 - prefix));
        long low = prefix <= 64 ? 0L : -1L << (128 - prefix);
        return new Ipv6Address(high, low);
    }

    public Ipv6Address and(Ipv6Address other) {
        return new Ipv6Address(high & other.high, low & other.low);
    }

    public Ipv6Address or(Ipv6Address other) {
        return new Ipv6Address(high | other.high, low | other.low);
    }

    public Ipv6Address not() {
        return new Ipv6Address(~high, ~low);
    }
```

- [ ] **Step 4 : 🎓 À toi — écrire `plus` et `shiftLeft`**

Indices :
- `plus` : additionner les `low`, puis comparer le résultat à l'ancien `low` **sans signe** ; s'il est plus petit, on a fait le tour : retenue de 1 ;
- `shiftLeft(bits)` : trois cas, `bits == 0` (attention, `low >>> 64` vaut `low`), `bits >= 64` (tout `low` passe dans `high`) et le cas général, où les `bits` bits de poids fort de `low` (`low >>> (64 - bits)`) rejoignent `high`.

**Implémentation de référence :**

```java
    /** Addition sur 128 bits : si low « fait le tour », on reporte une retenue sur high. */
    public Ipv6Address plus(Ipv6Address other) {
        long sumLow = low + other.low;
        long carry = Long.compareUnsigned(sumLow, low) < 0 ? 1 : 0;
        return new Ipv6Address(high + other.high + carry, sumLow);
    }

    /** Décalage à gauche sur 128 bits (0 à 127) : les bits de poids fort de low passent dans high. */
    public Ipv6Address shiftLeft(int bits) {
        if (bits < 0 || bits > 127) {
            throw new IllegalArgumentException("Décalage hors limites : " + bits);
        }
        if (bits == 0) {
            return this;
        }
        if (bits >= 64) {
            return new Ipv6Address(low << (bits - 64), 0L);
        }
        return new Ipv6Address((high << bits) | (low >>> (64 - bits)), low << bits);
    }
```

```java
package com.coco.subnet.model;

import java.math.BigInteger;
import java.util.Objects;
import java.util.Optional;

import static com.coco.subnet.model.ErrorCode.EMPTY_INPUT;
import static com.coco.subnet.model.ErrorCode.INVALID_PREFIX;
import static com.coco.subnet.model.ErrorCode.MISSING_PREFIX;
import static com.coco.subnet.model.ErrorCode.MULTIPLE_SLASHES;
import static com.coco.subnet.model.ErrorCode.PREFIX_OUT_OF_RANGE;

/** Une adresse IPv6 et un préfixe, par exemple 2001:db8:acad::/48. */
public record Ipv6Cidr(Ipv6Address address, int prefix) {

    public Ipv6Cidr {
        Objects.requireNonNull(address, "address");
        if (prefix < 0 || prefix > 128) {
            throw new IllegalArgumentException("Préfixe hors limites : " + prefix);
        }
    }

    /** Ordre des vérifications : vide → nombre de '/' → adresse → préfixe (comme Cidr). */
    public static Ipv6Cidr parse(String input, String field) {
        if (input == null || input.isBlank()) {
            throw InvalidInputException.of(EMPTY_INPUT, field, "L'adresse est obligatoire");
        }
        String text = input.strip();
        int slash = text.indexOf('/');
        if (slash < 0) {
            throw InvalidInputException.of(MISSING_PREFIX, field,
                    "Préfixe manquant : format attendu adresse/n, par exemple 2001:db8::/32");
        }
        if (text.indexOf('/', slash + 1) >= 0) {
            throw InvalidInputException.of(MULTIPLE_SLASHES, field, "Un seul '/' autorisé");
        }
        Ipv6Address address = Ipv6Address.parseStrict(text.substring(0, slash), field);
        String prefixText = text.substring(slash + 1);
        if (!prefixText.matches("[0-9]{1,3}")) {
            throw InvalidInputException.of(INVALID_PREFIX, field, "Le préfixe doit être un nombre entier positif");
        }
        int prefix = Integer.parseInt(prefixText);
        if (prefix > 128) {
            throw InvalidInputException.of(PREFIX_OUT_OF_RANGE, field, "Le préfixe doit être compris entre 0 et 128");
        }
        return new Ipv6Cidr(address, prefix);
    }

    public Ipv6Address mask() {
        return Ipv6Address.maskOf(prefix);
    }

    public Ipv6Address networkAddress() {
        return address.and(mask());
    }

    /** Il n'y a pas de broadcast en IPv6 : c'est simplement la dernière adresse du bloc. */
    public Ipv6Address lastAddress() {
        return networkAddress().or(mask().not());
    }

    public boolean isNetworkAddress() {
        return address.equals(networkAddress());
    }

    public Ipv6Cidr toNetwork() {
        return new Ipv6Cidr(networkAddress(), prefix);
    }

    /** Nombre d'adresses du bloc : 2^(128 - n), jusqu'à 2^128 pour un /0, d'où le BigInteger. */
    public BigInteger size() {
        return BigInteger.ONE.shiftLeft(128 - prefix);
    }

    public Optional<String> correctionWarning() {
        return isNetworkAddress()
                ? Optional.empty()
                : Optional.of("Adresse corrigée vers le réseau " + toNetwork());
    }

    @Override
    public String toString() {
        return address + "/" + prefix;
    }
}
```

```java
package com.coco.subnet.service;

import com.coco.subnet.model.InputError;
import com.coco.subnet.model.InvalidInputException;
import com.coco.subnet.model.Ipv6Address;
import com.coco.subnet.model.Ipv6AllocatedSubnet;
import com.coco.subnet.model.Ipv6Cidr;
import com.coco.subnet.model.Ipv6Plan;
import com.coco.subnet.model.Ipv6Requirement;
import com.coco.subnet.model.PlanMode;
import org.springframework.stereotype.Service;

import java.math.BigInteger;
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Locale;
import java.util.Set;
import java.util.regex.Pattern;
import java.util.stream.IntStream;

import static com.coco.subnet.model.ErrorCode.DUPLICATE_NAME;
import static com.coco.subnet.model.ErrorCode.DUPLICATE_VLAN_ID;
import static com.coco.subnet.model.ErrorCode.EMPTY_NAME;
import static com.coco.subnet.model.ErrorCode.INVALID_NAME;
import static com.coco.subnet.model.ErrorCode.MISSING_FIELD;
import static com.coco.subnet.model.ErrorCode.NETWORK_TOO_SMALL;
import static com.coco.subnet.model.ErrorCode.NO_REQUIREMENTS;
import static com.coco.subnet.model.ErrorCode.PARENT_NOT_SPLITTABLE;
import static com.coco.subnet.model.ErrorCode.SUBNET_PREFIX_OUT_OF_RANGE;
import static com.coco.subnet.model.ErrorCode.TOO_MANY_REQUIREMENTS;
import static com.coco.subnet.model.ErrorCode.VLAN_COUNT_OUT_OF_RANGE;
import static com.coco.subnet.model.ErrorCode.VLAN_ID_OUT_OF_RANGE;

/** Découpe un préfixe IPv6 en sous-réseaux de même taille, un par VLAN ou par besoin nommé. */
@Service
public class Ipv6PlanService {

    public static final int DEFAULT_SUBNET_PREFIX = 64;
    private static final int MAX_SUBNET_PREFIX = 127;
    /** Même règle que la v1 : empêche aussi l'injection de formules dans Excel. */
    private static final Pattern NAME = Pattern.compile("^[\\p{L}\\p{N}][\\p{L}\\p{N}_-]{0,31}$");

    public Ipv6Plan allocate(String networkText, Integer subnetPrefix, PlanMode mode, List<Ipv6Requirement> requirements) {
        List<InputError> errors = new ArrayList<>();
        Ipv6Cidr parent = parseParent(networkText, errors);
        validateSubnetPrefix(errors.isEmpty() ? parent : null, subnetPrefix, errors);
        List<Ipv6Requirement> resolved = validateRequirements(mode, requirements, errors);
        throwIfAny(errors);
        // Les vérifications globales n'ont de sens que si chaque champ est valide
        checkDuplicates(mode, resolved, errors);
        throwIfAny(errors);
        Ipv6Cidr network = parent.toNetwork();
        BigInteger available = BigInteger.ONE.shiftLeft(subnetPrefix - network.prefix());
        if (available.compareTo(BigInteger.valueOf(resolved.size())) < 0) {
            throw InvalidInputException.of(NETWORK_TOO_SMALL, "network", "Le /" + network.prefix() + " contient "
                    + available + " sous-réseaux /" + subnetPrefix + " : " + resolved.size() + " demandés, il en manque "
                    + (resolved.size() - available.intValue()));
        }
        List<Ipv6AllocatedSubnet> subnets = new ArrayList<>();
        for (int i = 0; i < resolved.size(); i++) {
            // Début du n° i : réseau + i × 2^(128 - préfixe), soit i décalé de (128 - préfixe) bits
            Ipv6Address start = network.address().plus(new Ipv6Address(0, i).shiftLeft(128 - subnetPrefix));
            Ipv6Address gateway = mode == PlanMode.VLAN ? start.plus(Ipv6Address.ONE) : null;
            subnets.add(new Ipv6AllocatedSubnet(resolved.get(i), new Ipv6Cidr(start, subnetPrefix), gateway));
        }
        List<String> warnings = new ArrayList<>(parent.correctionWarning().stream().toList());
        if (subnetPrefix > DEFAULT_SUBNET_PREFIX) {
            warnings.add("Sous-réseaux /" + subnetPrefix + " : plus longs que /64, l'autoconfiguration SLAAC ne fonctionnera pas");
        } else if (subnetPrefix < DEFAULT_SUBNET_PREFIX) {
            warnings.add("Sous-réseaux /" + subnetPrefix + " : plus courts que /64 ; un réseau local utilise normalement un /64");
        }
        return new Ipv6Plan(network, subnetPrefix, mode, List.copyOf(subnets), available, List.copyOf(warnings));
    }

    /** Raccourci : VLAN10, VLAN20… modifiables ensuite. */
    public List<Ipv6Requirement> generateVlans(Integer vlanCount) {
        if (vlanCount == null) {
            throw InvalidInputException.of(MISSING_FIELD, "vlanCount", "Le champ « Nombre de VLAN » est obligatoire");
        }
        if (vlanCount < 1 || vlanCount > VlsmService.MAX_VLAN_COUNT) {
            throw InvalidInputException.of(VLAN_COUNT_OUT_OF_RANGE, "vlanCount", "Le nombre de VLAN doit être entre 1 et 100");
        }
        return IntStream.rangeClosed(1, vlanCount)
                .mapToObj(i -> new Ipv6Requirement(i * 10, "VLAN" + (i * 10)))
                .toList();
    }

    private static Ipv6Cidr parseParent(String networkText, List<InputError> errors) {
        try {
            Ipv6Cidr parent = Ipv6Cidr.parse(networkText, "network");
            if (parent.prefix() >= MAX_SUBNET_PREFIX) {
                errors.add(new InputError(PARENT_NOT_SPLITTABLE, "network", "Un /127 ou /128 ne peut pas être découpé"));
            }
            return parent;
        } catch (InvalidInputException e) {
            errors.addAll(e.errors());
            return null;
        }
    }

    /** parent est null s'il est invalide ou non découpable : on vérifie alors seulement 1 à 127. */
    private static void validateSubnetPrefix(Ipv6Cidr parent, Integer subnetPrefix, List<InputError> errors) {
        if (subnetPrefix == null) {
            errors.add(new InputError(MISSING_FIELD, "subnetPrefix", "Le champ « Taille des sous-réseaux » est obligatoire"));
            return;
        }
        int min = parent == null ? 1 : parent.prefix() + 1;
        if (subnetPrefix < min || subnetPrefix > MAX_SUBNET_PREFIX) {
            errors.add(new InputError(SUBNET_PREFIX_OUT_OF_RANGE, "subnetPrefix",
                    "La taille des sous-réseaux doit être comprise entre /" + min + " et /" + MAX_SUBNET_PREFIX));
        }
    }

    private static List<Ipv6Requirement> validateRequirements(PlanMode mode, List<Ipv6Requirement> requirements,
                                                              List<InputError> errors) {
        String list = listField(mode);
        if (requirements == null || requirements.isEmpty()) {
            errors.add(new InputError(NO_REQUIREMENTS, list, "Ajoutez au moins un VLAN ou un besoin"));
            return List.of();
        }
        if (requirements.size() > VlsmService.MAX_REQUIREMENTS) {
            errors.add(new InputError(TOO_MANY_REQUIREMENTS, list, "Maximum 100 sous-réseaux"));
            return List.of();
        }
        List<Ipv6Requirement> resolved = new ArrayList<>();
        for (int i = 0; i < requirements.size(); i++) {
            Ipv6Requirement row = requirements.get(i) == null ? new Ipv6Requirement(null, null) : requirements.get(i);
            resolved.add(validateRow(mode, i, row, errors));
        }
        return resolved;
    }

    /** Valide une ligne et renvoie le besoin « résolu » (nom nettoyé, nom par défaut en VLAN). */
    private static Ipv6Requirement validateRow(PlanMode mode, int index, Ipv6Requirement row, List<InputError> errors) {
        String path = listField(mode) + "[" + index + "].";
        String name = row.name() == null ? "" : row.name().strip();
        Integer vlanId = null;
        String label;
        if (mode == PlanMode.VLAN) {
            vlanId = row.vlanId();
            if (vlanId == null) {
                errors.add(new InputError(MISSING_FIELD, path + "id", "Ligne " + (index + 1) + " : l'ID du VLAN est obligatoire"));
                label = "Ligne " + (index + 1);
            } else if (vlanId < 1 || vlanId > VlsmService.MAX_VLAN_ID) {
                errors.add(new InputError(VLAN_ID_OUT_OF_RANGE, path + "id", "VLAN " + vlanId + " : l'ID doit être entre 1 et 4094"));
                label = "Ligne " + (index + 1);
            } else {
                label = "VLAN " + vlanId;
            }
            if (name.isEmpty() && vlanId != null) {
                name = "VLAN" + vlanId;
            }
        } else {
            label = "Besoin n°" + (index + 1);
            if (name.isEmpty()) {
                errors.add(new InputError(EMPTY_NAME, path + "name", "Le besoin n°" + (index + 1) + " doit avoir un nom"));
            }
        }
        if (!name.isEmpty() && !NAME.matcher(name).matches()) {
            errors.add(new InputError(INVALID_NAME, path + "name",
                    label + " : nom invalide : lettres (accents compris), chiffres, - et _ (32 max)"));
        }
        return new Ipv6Requirement(vlanId, name);
    }

    private static void checkDuplicates(PlanMode mode, List<Ipv6Requirement> requirements, List<InputError> errors) {
        String list = listField(mode);
        Set<Integer> ids = new HashSet<>();
        Set<String> names = new HashSet<>();
        for (int i = 0; i < requirements.size(); i++) {
            Ipv6Requirement r = requirements.get(i);
            if (mode == PlanMode.VLAN && !ids.add(r.vlanId())) {
                errors.add(new InputError(DUPLICATE_VLAN_ID, list + "[" + i + "].id", "VLAN " + r.vlanId() + " est en double"));
                continue; // même ID → même nom par défaut : une seule erreur suffit
            }
            if (!names.add(r.name().toLowerCase(Locale.ROOT))) {
                errors.add(new InputError(DUPLICATE_NAME, list + "[" + i + "].name", "Le nom '" + r.name() + "' est utilisé deux fois"));
            }
        }
    }

    private static String listField(PlanMode mode) {
        return mode == PlanMode.VLAN ? "vlans" : "subnets";
    }

    private static void throwIfAny(List<InputError> errors) {
        if (!errors.isEmpty()) {
            throw new InvalidInputException(errors);
        }
    }
}
```
